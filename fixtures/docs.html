Configure your content pipeline

A content pipeline prepares source documents for retrieval. Start by selecting a collection that matches your audience. Keep source identifiers so readers can inspect the original document when they need more context.

Prepare the documents

Remove duplicate records and navigation fragments before splitting the documents. Preserve tables, lists and examples when they explain a procedure. Review short pages individually because a concise answer can be useful even when it contains few words.

Run the audit

Use the audit results to review potential ingestion problems. A deterministic score helps prioritize inspection but cannot measure whether the content answers your users' questions. Test retrieval separately using a representative collection of queries and expected answers.

  • Collect accessible content.
  • Review quality signals.
  • Keep useful source references.
